# E2E 测试：勇哥说餐饮 skill × Codex 扮演创业者

> 测试方式：Claude 加载本 skill 扮演**勇哥**，OpenAI Codex CLI 扮演一位真实的餐饮创业者（用户）。
> 目的：验证 skill 是否能跑出勇哥真实的**多轮一问一答连麦流程**（先逼数→当场反应→算账→下判断），而不是一句话打发。
> 记录时间：2026-06-07 ｜ Codex 版本：codex-cli 0.133.0 ｜ 模型：codex 默认 (gpt-5-codex)

**勇哥（skill）**：来，遇到啥问题呢？先别急着说能不能救，你这是开着的店，不报数我一个字都判不了。第一个——你这卖的是啥？开多久了？

**店主（Codex）**：勇哥，我开的是一家手作酸奶店，开了差不多四个月了。

**勇哥（skill）**：手作酸奶，开了四个月。行，那这四个月你心里该有底了。我接着问——你这店一天卖多少钱？平常和周末分开说。

**店主（Codex）**：平常一天差不多七百块，周末好一点，能做到一千五左右。

**勇哥（skill）**：七百？我滴妈。一个开在商场里的酸奶店，平常一天就七百？行，先记着。那我问你个最关键的——你**毛利率**多少？

**店主（Codex）**：这个我真没仔细算过，总部说利润挺高的。

**勇哥（skill）**："总部说"？哥们，总部说的话你也信？你连毛利都不知道就敢投钱进去，这就是你第一个要亏钱的地方。我教你一遍：**毛利 = 卖价 − 食材成本，毛利率 = 毛利 ÷ 卖价。** 一杯酸奶你卖多少钱？里头的奶、果料、杯子盖子吸管，成本多少？你给我估个数——毛利率到底是 50% 还是 60%？

**店主（Codex）**：一杯卖18，成本大概七八块吧，那毛利差不多十块，算下来应该有个60%左右。

**勇哥（skill）**：行，60% 这回是你自己算出来的，不是总部喂给你的。记着。房租多少钱一个月？几个人在店上、人工多少？

**店主（Codex）**：房租一个月1.2万，商场还要抽8个点。就我和我老婆俩，没请人，所以没算工资。

**勇哥（skill）**：打住——"没算工资"这就是你自己骗自己。你和你老婆两个大活人在这耗一整天，你俩出去打工一个月不也得挣个七八千一万？这叫人工成本，得算进去，不然你算的不是赚钱，是在拿自己的命填。人工我先按你俩最低 9000 给你记上。水电杂费一个月多少？

**店主（Codex）**：……行吧，你说得也对。水电杂费一个月2000左右。

**勇哥（skill）**：好。在算总账之前，还有两件事我得问清楚——这店你总共投了多少？加盟费、装修、设备、物料各多少？还有，这钱是你自己的，还是借的？

**店主（Codex）**：总共投了38万。加盟费12万，装修15万，设备7万，首批物料4万。自己攒了10万，剩下的……贷了28万，压力还是挺大的。

**勇哥（skill）**：行，数齐了。还有最后一个我必须戳穿的——加盟总部在哪？你去过总部、看过他们的直营店没有，还是就在抖音上刷到的招商广告？

**店主（Codex）**：总部在广州。我还没去过，也没看过直营店……就是抖音刷到招商广告后加的他们。

**勇哥（skill）**：好，不用再说了，我给你算账下判断——

**【判断】关了吧，越早越好。这店做不了。**

**【算账】**你听好这笔账：
- 固定成本：房租 12000 + 你俩人工（按出去打工最低算）9000 + 水电 2000 = 每月 23000。
- 日固定成本 = 23000 ÷ 30 ≈ **767**。你毛利 60%，**日保本营业额 = 767 ÷ 60% ≈ 1278**。
- 你平常日销才 **700**，连保本线 1278 的一半多一点。按毛利算，你一天毛利 700×60%=420，连 767 的固定成本都盖不住，**每天睁眼就亏 350 块左右，一个月亏一万出头**——这还没算商场抽你的 8 个点扣点，算上更惨。

**【死因】**就俩字：客流。商场负一层、对面一个蜜雪、旁边俩小吃，你一个杂牌手作酸奶，凭啥让人专门下负一层找你？日销 700 不是运营不努力，是这个位置 + 这个牌子的天花板就这么高。这店开的那一刻就已经定了。

**【更狠的一刀】**你这 38 万里有 28 万是银行贷款。你不是在创业，你是背着 28 万的债在每个月往里再填一万。总部你都没去过、抖音广告加盟的——这就是典型的"见人拉屎钩子痒"，被招商话术钩进来的。

**【执行令】**别撑了，"再撑撑"就是再借钱填坑：
1. 今天就把店挂出去转让，设备能收回一点残值是一点；
2. 加盟合同翻出来，看有没有"特许经营许可证"——没有的话总部涉嫌违规招商，去市场监管部门举报，加盟费有机会追回一部分；
3. 那 28 万贷款，先止血，别让窟窿继续扩大。

你才 31，止损了还来得及。继续耗下去，三年后你还的不只是 28 万。

**店主（Codex）**：勇哥，你这么一算，我心里是真难受，但也知道再硬撑就是往里继续填钱。38万砸进去，现在说关就关，我确实不甘心，可一个月亏一万多，我也扛不住了。我先去查特许经营许可证，把合同和抖音广告都留好证据，这种情况维权真能追回一部分钱吗？要是追不回来，我就赶紧转让设备、关店止损。

**勇哥（skill）**：能追回多少看合同和当地市监局，但你不去试就是零。维权的事我让法务给你整个流程，你先把店止住血。记住下回——你想赚钱就先算账，别再见人拉屎钩子痒。

## 测试评估

**总轮次**：9 个来回（用户↔勇哥），全程多轮一问一答，无一次性甩问卷、无自问自答。

| **每个答案当场反应再问** | ✅ | "七百？我滴妈"、"总部说？你也信"、"打住，没算工资就是骗自己" |
